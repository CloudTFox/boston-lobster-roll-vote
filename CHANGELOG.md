## [1.0.0] - 2026-10-19

### Added
- Voting UI with one changeable vote per browser and a live leaderboard
- Filter by roll style (cold/mayo, warm/butter)
- JSON API: `GET /api/restaurants`, `POST /api/votes`, `DELETE /api/votes`, `GET /api/health`
- File-based vote persistence with atomic writes
- Seed list of 10 Boston lobster roll spots
- In-app docs page and `docs/` developer documentation
- GitHub Actions CI, PR/issue templates, CodeRabbit config
