# Contributing

Thanks for helping crown Boston's best lobster roll!

1. Fork and clone the repo.
2. Create a branch: `git switch -c feat/your-change` (see [branch prefixes](docs/git-workflow.md#branching)).
3. Make your change and add tests where it makes sense.
4. Run `npm run lint && npm test`.
5. Commit using [Conventional Commits](docs/git-workflow.md#commit-messages).
6. Open a pull request and fill out the template.

**Nominating a spot?** Use the "Nominate a lobster roll" issue template, or follow
[docs/restaurants.md](docs/restaurants.md) and open a PR.
