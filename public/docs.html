Documentation

Everything you need to use Lobster Roll Vote. Developer docs live in the docs/ folder of the Git repository.

How to vote

  1. Browse the contenders on the Vote page. Use the filter chips to narrow by style.
  2. Click Vote on your favorite. The card is highlighted and the leaderboard updates instantly.
  3. Changed your mind? Click Vote on a different spot and your vote moves there.
  4. To remove your vote entirely, click Your pick ✓ again or use Withdraw vote under the leaderboard.

Voting rules

  • One vote per browser. Your browser receives an anonymous ID cookie the first time you vote. No account or personal data is collected.
  • Votes are changeable. Re-voting moves your single vote; it never adds a second one.
  • Results are live. The leaderboard refreshes every 15 seconds while the page is open. Percentages are each spot's share of all votes.
  • Clearing cookies or switching browsers gives you a fresh ID. This is a fun poll, not an election.

API

The app is powered by a small JSON API you can call directly.

MethodPathDescription
GET/api/restaurantsStandings, total votes and your current vote
POST/api/votesCast or move your vote. Body: {"restaurantId": "neptune-oyster"}
DELETE/api/votesWithdraw your vote
GET/api/healthHealth check
curl -c jar -b jar -X POST localhost:3000/api/votes \
  -H 'Content-Type: application/json' \
  -d '{"restaurantId":"row-34"}'

Full request/response details: docs/api.md.

FAQ

My favorite spot isn't listed. Open an issue or pull request adding it to data/restaurants.json. See docs/restaurants.md.

Where are votes stored? In data/votes.json on the server. That file is git-ignored so real votes never end up in the repository.

Can I reset the results? Stop the server and delete data/votes.json.
